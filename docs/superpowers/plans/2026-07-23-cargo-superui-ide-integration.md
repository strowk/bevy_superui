# cargo-superui IDE Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a `cargo-superui` CLI whose `install` command projects supersolid's editor types into a gitignored `superui_modules/` tree + a `tsconfig.json`, so `.tsx` authors get IntelliSense with zero hand-maintained shims.

**Architecture:** A single canonical, doc-commented `.d.ts` ships inside the `supersolid` crate. `cargo superui install` locates that crate via `cargo metadata`, copies the `.d.ts` into `<app>/superui_modules/supersolid/index.d.ts`, writes/guides a `tsconfig.json` whose `paths` make `import … from "supersolid"` resolve like `node_modules`, and gitignores the generated tree. The four in-repo examples are migrated to dogfood it.

**Tech Stack:** Rust (std + `serde`/`serde_json`), cargo external subcommand convention, TypeScript `tsconfig` path mapping.

## Global Constraints

- CLI crate: `crates/cargo-superui`, binary name **`cargo-superui`** (invocable as both `cargo superui …` and `cargo-superui …`). `publish = false` for this slice.
- The `.d.ts` is **editor-only**: the transpiler erases the `supersolid` import; nothing here affects build/runtime. Say so in the file header.
- Canonical types live at **`crates/supersolid/supersolid.d.ts`** — the one hand-edited copy. Projected copies are derived artifacts, overwritten on every `install`, and never committed.
- Projected `superui_modules/` goes **beside `assets/`, never inside it** (`assets/` is the runtime-loaded, wasm-packaged tree).
- `superui_modules/` is gitignored; `tsconfig.json` IS committed.
- Explicit per-module `paths` entries (no `"*"` wildcard).
- Deferred (do NOT implement): component-crate projection, `[package.metadata.superui]` parsing, capability ledger, JSONC-preserving tsconfig merge, auto-run-on-build, crates.io publish.

```ts
/**
 * Ambient type declarations for the `supersolid` authoring API.
 *
 * These types exist ONLY for the editor / TypeScript language server. superui's
 * Rust transpiler is the real consumer of `.tsx`: it strips the types and erases
 * the `import ... from "supersolid"` — the reactive primitives and control-flow
 * components are injected by the runtime (the `$ss.*` ABI). Nothing here affects
 * the build or runtime; it only powers autocomplete, hover docs, and type-checking.
 *
 * Do NOT edit this file inside a project — it is projected (copied) by
 * `cargo superui install` and will be overwritten. Edit the canonical copy at
 * `crates/supersolid/supersolid.d.ts`.
 */

declare module "supersolid" {
  /**
   * A reactive getter. Call it to read the current value AND — inside a tracking
   * scope (effect, memo, or JSX expression) — subscribe to future changes:
   * `count()`. Reading is what subscribes; there is no separate `.subscribe`.
   */
  export type Accessor<T> = () => T;
  /** Writes a signal's value, re-running exactly the bindings that read it. */
  export type Setter<T> = (next: T) => void;

  /**
   * Create a reactive signal — the fundamental unit of state.
   *
   * Returns a `[get, set]` tuple. Reading `get()` inside a tracking scope
   * subscribes that scope; `set(v)` re-runs exactly the subscribers that read it.
   * Components run once, so keep reads inline (`{count()}`) rather than caching
   * them in a variable at the top of the body.
   *
   * @example
   * const [count, setCount] = createSignal(0);
   * // in JSX:  <button onClick={() => setCount(count() + 1)}>{count()}</button>
   */
  export function createSignal<T>(value?: T): [Accessor<T>, Setter<T>];

  /**
   * Run a side effect that re-executes whenever any signal it reads changes.
   * The body runs once immediately, tracking its reactive reads.
   * @example createEffect(() => console.log("count is", count()));
   */
  export function createEffect(fn: () => void): void;

  /**
   * Create a derived, memoized signal. `fn` re-runs when its reactive
   * dependencies change; readers update only when the result actually changes.
   * Use for expensive or shared derivations.
   * @example const doubled = createMemo(() => count() * 2);
   */
  export function createMemo<T>(fn: () => T): Accessor<T>;

  /** Register a callback to run once, after the component's initial render. */
  export function onMount(fn: () => void): void;

  /**
   * Register cleanup to run when the enclosing reactive scope is disposed
   * (component unmounts, or a list row is removed).
   */
  export function onCleanup(fn: () => void): void;

  /** Read signals without subscribing — reads inside `fn` are not tracked. */
  export function untrack<T>(fn: () => T): T;

  /** Batch multiple writes so dependents recompute once, at the end. */
  export function batch<T>(fn: () => T): T;

  /** An injectable context created by {@link createContext}. */
  export interface Context<T> {
    readonly id: number;
    readonly defaultValue: T;
  }
  /**
   * Create a context carrying `defaultValue` for descendants to read via
   * {@link useContext}.
   */
  export function createContext<T>(defaultValue: T): Context<T>;
  /** Read the nearest provided value for `context` (or its default). */
  export function useContext<T>(context: Context<T>): T;

  /**
   * Mount a component tree into a DOM node. Call once at app entry.
   * @param code A function returning the root element (usually `() => <App/>`).
   * @param mount The container node to render into.
   */
  export function render(code: () => unknown, mount: unknown): void;

  // ---- Control-flow components ---------------------------------------------
  // Permissive on purpose: these are markup for a browser-like arena DOM, not
  // React elements. Inside a plain element, wrap them in `{...}`.

  /**
   * Render a list, re-mapping each item by IDENTITY across changes (a row is
   * reused when its item object survives a reorder). Prefer over {@link Index}
   * when list order matters.
   * @example <For each={items()}>{(item, i) => <li>{item.name}</li>}</For>
   */
  export const For: <T>(props: {
    each: readonly T[] | undefined | null;
    children: (item: T, index: Accessor<number>) => unknown;
  }) => unknown;

  /**
   * Render a list keyed by POSITION: the item is a signal, the index is fixed.
   * Prefer over {@link For} when items are primitives or only values change.
   * @example <Index each={rows()}>{(row, i) => <li>{row().label}</li>}</Index>
   */
  export const Index: <T>(props: {
    each: readonly T[] | undefined | null;
    children: (item: Accessor<T>, index: number) => unknown;
  }) => unknown;

  /**
   * Conditionally render `children` when `when` is truthy.
   * @example <Show when={loaded()}>{<Content />}</Show>
   */
  export const Show: (props: { when: unknown; children: unknown }) => unknown;

  /**
   * Overlay-style keyed list: reuse a mapped node per item identity WITHOUT
   * enforcing DOM order. Correct for absolutely-positioned overlays; use
   * {@link For} when order matters. `by` names the identity key field.
   */
  export const Keyed: (props: {
    each: unknown;
    by: string;
    children: unknown;
  }) => unknown;

  /**
   * Render the first matching {@link Match} child.
   * @example
   * <Switch>
   *   <Match when={loading()}>{<Spinner />}</Match>
   *   <Match when={error()}>{<ErrorView />}</Match>
   * </Switch>
   */
  export const Switch: (props: { children: unknown }) => unknown;
  /** A branch of {@link Switch}; renders `children` when `when` is truthy. */
  export const Match: (props: { when: unknown; children: unknown }) => unknown;
}

// ---------------------------------------------------------------------------
// With `jsx: preserve` and no jsxImportSource, TypeScript resolves intrinsic
// elements against the GLOBAL JSX namespace. Keep it permissive: this is markup
// for a browser-like arena DOM, not React, so React's element typings must not
// apply.
declare namespace JSX {
  interface IntrinsicElements {
    [name: string]: any;
  }
  type Element = any;
  interface ElementChildrenAttribute {
    children: {};
  }
}
```

```rust
use std::path::{Path, PathBuf};

use serde::Deserialize;

#[derive(Deserialize)]
struct Metadata {
    packages: Vec<Package>,
}

#[derive(Deserialize)]
struct Package {
    name: String,
    manifest_path: String,
}

/// Given `cargo metadata` JSON, locate the `supersolid` package and return the
/// path to its bundled `supersolid.d.ts` (a sibling of its `Cargo.toml`).
pub fn find_supersolid_dts(metadata_json: &str) -> Option<PathBuf> {
    let meta: Metadata = serde_json::from_str(metadata_json).ok()?;
    let pkg = meta.packages.into_iter().find(|p| p.name == "supersolid")?;
    let dir = Path::new(&pkg.manifest_path).parent()?;
    Some(dir.join("supersolid.d.ts"))
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn finds_supersolid_dts_from_metadata() {
        let json = r#"{
            "packages": [
                { "name": "superui", "manifest_path": "/w/crates/superui/Cargo.toml" },
                { "name": "supersolid", "manifest_path": "/w/crates/supersolid/Cargo.toml" }
            ]
        }"#;
        let got = find_supersolid_dts(json).unwrap();
        assert_eq!(got, PathBuf::from("/w/crates/supersolid/supersolid.d.ts"));
    }

    #[test]
    fn returns_none_when_supersolid_absent() {
        let json = r#"{ "packages": [ { "name": "bevy", "manifest_path": "/x/Cargo.toml" } ] }"#;
        assert!(find_supersolid_dts(json).is_none());
    }
}
```

```rust
/// Marker substring identifying the projected supersolid module in a tsconfig.
pub const SUPERSOLID_PATH_MARKER: &str = "superui_modules/supersolid";

/// The `.gitignore` line that hides the derived module tree.
pub const GITIGNORE_ENTRY: &str = "superui_modules/";

/// tsconfig written verbatim when an app dir has none. Makes
/// `import ... from "supersolid"` resolve to the projected module.
pub const TSCONFIG_TEMPLATE: &str = r#"{
  "compilerOptions": {
    "jsx": "preserve",
    "module": "esnext",
    "moduleResolution": "bundler",
    "target": "esnext",
    "noEmit": true,
    "baseUrl": ".",
    "paths": {
      "supersolid": ["./superui_modules/supersolid/index.d.ts"]
    }
  },
  "include": ["superui_modules/**/*.d.ts", "assets/**/*.ts", "assets/**/*.tsx"]
}
"#;

/// True if the tsconfig source already maps the supersolid module. Substring
/// check (not a JSONC parse) — sufficient because the projected path is unique.
pub fn tsconfig_has_supersolid_path(src: &str) -> bool {
    src.contains(SUPERSOLID_PATH_MARKER)
}

/// True if `.gitignore` source lacks a line ignoring the module tree.
pub fn gitignore_needs_entry(src: &str) -> bool {
    !src.lines().any(|l| l.trim() == GITIGNORE_ENTRY.trim_end_matches('/')
        || l.trim() == GITIGNORE_ENTRY)
}
```

```rust
use std::path::{Path, PathBuf};
use std::process::Command;

use superui_cli::{
    find_supersolid_dts, gitignore_needs_entry, tsconfig_has_supersolid_path, GITIGNORE_ENTRY,
    SUPERSOLID_PATH_MARKER, TSCONFIG_TEMPLATE,
};

fn main() {
    if let Err(e) = run() {
        eprintln!("cargo-superui: {e}");
        std::process::exit(1);
    }
}

fn run() -> Result<(), Box<dyn std::error::Error>> {
    let mut args: Vec<String> = std::env::args().skip(1).collect();
    // Invoked as `cargo superui install`, cargo passes "superui" as the first arg.
    if args.first().map(String::as_str) == Some("superui") {
        args.remove(0);
    }
    match args.first().map(String::as_str) {
        Some("install") => install(&args[1..]),
        other => Err(format!("unknown command {other:?}; try `cargo superui install`").into()),
    }
}

/// Minimal `--flag value` parser.
fn flag(args: &[String], name: &str) -> Option<String> {
    args.iter().position(|a| a == name).and_then(|i| args.get(i + 1).cloned())
}

fn install(args: &[String]) -> Result<(), Box<dyn std::error::Error>> {
    let app_dir = match flag(args, "--path") {
        Some(p) => PathBuf::from(p),
        None => current_package_dir()?,
    };

    // Locate supersolid's bundled types via the resolved dependency graph.
    let metadata = run_cargo(&["metadata", "--format-version", "1"])?;
    let dts_src = find_supersolid_dts(&metadata)
        .ok_or("no `supersolid` dependency resolved — add it (or `superui`) to Cargo.toml")?;
    let dts = std::fs::read_to_string(&dts_src)
        .map_err(|e| format!("reading {}: {e}", dts_src.display()))?;

    // 1. Project the types (derived artifact — always overwrite).
    let module_dir = app_dir.join("superui_modules").join("supersolid");
    std::fs::create_dir_all(&module_dir)?;
    let index = module_dir.join("index.d.ts");
    std::fs::write(&index, &dts)?;
    println!("wrote {}", index.display());

    // 2. tsconfig: create if absent, else guide.
    let tsconfig = app_dir.join("tsconfig.json");
    if !tsconfig.exists() {
        std::fs::write(&tsconfig, TSCONFIG_TEMPLATE)?;
        println!("wrote {}", tsconfig.display());
    } else {
        let existing = std::fs::read_to_string(&tsconfig)?;
        if tsconfig_has_supersolid_path(&existing) {
            println!("ok   {} (already maps supersolid)", tsconfig.display());
        } else {
            println!(
                "note {} exists but does not map supersolid — add to compilerOptions.paths:\n      \"supersolid\": [\"./{}/index.d.ts\"]",
                tsconfig.display(),
                SUPERSOLID_PATH_MARKER
            );
        }
    }

    // 3. .gitignore the derived tree.
    let gitignore = app_dir.join(".gitignore");
    let existing = std::fs::read_to_string(&gitignore).unwrap_or_default();
    if gitignore_needs_entry(&existing) {
        let mut next = existing;
        if !next.is_empty() && !next.ends_with('\n') {
            next.push('\n');
        }
        next.push_str(GITIGNORE_ENTRY);
        next.push('\n');
        std::fs::write(&gitignore, next)?;
        println!("updated {}", gitignore.display());
    }

    println!("done: supersolid IDE types installed in {}", app_dir.display());
    Ok(())
}

/// Directory of the nearest package manifest (from cwd), via `cargo locate-project`.
fn current_package_dir() -> Result<PathBuf, Box<dyn std::error::Error>> {
    let out = run_cargo(&["locate-project", "--message-format", "plain"])?;
    let manifest = out.trim();
    let dir = Path::new(manifest)
        .parent()
        .ok_or("could not determine package directory")?;
    Ok(dir.to_path_buf())
}

/// Run a cargo subcommand and return stdout, erroring on non-zero exit.
fn run_cargo(args: &[&str]) -> Result<String, Box<dyn std::error::Error>> {
    let cargo = std::env::var("CARGO").unwrap_or_else(|_| "cargo".into());
    let out = Command::new(cargo).args(args).output()?;
    if !out.status.success() {
        return Err(format!(
            "`cargo {}` failed: {}",
            args.join(" "),
            String::from_utf8_lossy(&out.stderr)
        )
        .into());
    }
    Ok(String::from_utf8(out.stdout)?)
}
```
