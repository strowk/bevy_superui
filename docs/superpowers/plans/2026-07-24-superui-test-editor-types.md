# superui/test Editor Types Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `.spec.ts` authors full editor IntelliSense and type-checking for the `superui/test` API by projecting a hand-maintained `.d.ts` through `cargo superui install`.

**Architecture:** A self-contained `superui-test.d.ts` ships beside the `superui` crate and mirrors `crates/superui_test_engine/src/prelude.js` exactly. `cargo superui install` is generalized from projecting one hardcoded module (supersolid) to iterating a small module table, projecting each into the gitignored `superui_modules/` tree and mapping it via tsconfig `paths`.

**Tech Stack:** Rust (`cargo-superui` crate, lib name `superui_cli`), TypeScript declaration files, `cargo metadata`, tsc (via `npx -p typescript`).

## Global Constraints

- The `.d.ts` mirrors `prelude.js` **exactly** — no aspirational Playwright surface. Specifically: **no `.not`**, **no `last()`**; `hasText` is `string` only; `toHaveClass` takes `RegExp | string`; all actions/matchers return `Promise<void>`.
- The `.d.ts` is **self-contained** — it does not import or reference DOM/supersolid types.
- Canonical `.d.ts` lives at `crates/superui/superui-test.d.ts`; projected copies are derived artifacts (always overwritten, gitignored) and MUST NOT be hand-edited.
- Projected path mirrors the import specifier: `superui_modules/superui/test/index.d.ts`, tsconfig key `"superui/test"`.
- No runtime behavior change; types are editor-only.
- `supersolid` remains the **required** (primary) module — its absence is a hard error. `superui` (test types) is **optional** — absence is a skip-with-note.
- **Type verification is a human checkpoint, not tsc/npx.** Automated coverage is the Rust unit tests (projection logic) plus the installer smoke-run. Final proof that the `.d.ts` matches real usage is the user opening `examples/game_menu/tests/game_menu.spec.ts` in VS Code and confirming no errors + working autocomplete. The orchestrator surfaces this checkpoint; subagents do not run tsc.
- The crate's library name is `superui_cli`; its package name is `cargo-superui`. Run unit tests with `cargo test -p cargo-superui`.

```ts
/**
 * Ambient type declarations for the `superui/test` authoring API.
 *
 * These types exist ONLY for the editor / TypeScript language server. superui's
 * `superui_test` CLI is the real consumer of `.spec.ts`: it strips the types and
 * erases the `import ... from "superui/test"` — `test`, `expect`, and `page` are
 * injected by the test-engine prelude. Nothing here affects the runtime; it only
 * powers autocomplete, hover docs, and type-checking.
 *
 * This surface mirrors `crates/superui_test_engine/src/prelude.js` EXACTLY. It is
 * intentionally NOT full Playwright: there is no `.not`, no `last()`, `hasText` is
 * a plain string, and every action/matcher resolves to `Promise<void>`.
 *
 * Do NOT edit this file inside a project — it is projected (copied) by
 * `cargo superui install` and will be overwritten. Edit the canonical copy at
 * `crates/superui/superui-test.d.ts`.
 */

declare module "superui/test" {
  /** Options for narrowing a `locator(...)` query. */
  export interface LocatorOptions {
    /**
     * Keep only elements whose text contains this substring. The runtime
     * stringifies the value, so pass a plain string (a RegExp is not supported).
     */
    hasText?: string;
  }

  /** A lazily-evaluated, chainable handle to DOM node(s), resolved when acted on. */
  export interface Locator {
    /** Narrow to descendants matching `selector` (optionally filtered by text). */
    locator(selector: string, options?: LocatorOptions): Locator;
    /** Select the match at `index` (0-based). */
    nth(index: number): Locator;
    /** Select the first match (alias for `nth(0)`). */
    first(): Locator;
    /** Click the resolved element, auto-waiting for it to appear. */
    click(): Promise<void>;
    /** Replace the resolved input's value with `text`. */
    fill(text: string): Promise<void>;
    /** Dispatch a key press to the resolved element. */
    press(key: string): Promise<void>;
    /** Hover the resolved element. */
    hover(): Promise<void>;
  }

  /** The mounted app page — the root from which locators are queried. */
  export interface Page {
    /** Start a locator query at the page root. */
    locator(selector: string, options?: LocatorOptions): Locator;
  }

  /** Auto-waiting assertions returned by `expect(...)`. Each resolves when it passes. */
  export interface Matchers {
    /** Assert the target is attached and not hidden. */
    toBeVisible(): Promise<void>;
    /** Assert the target's text content equals `text`. */
    toHaveText(text: string): Promise<void>;
    /** Assert the target resolves to exactly `count` nodes. */
    toHaveCount(count: number): Promise<void>;
    /** Assert the target's class list matches (RegExp source or literal string). */
    toHaveClass(expected: RegExp | string): Promise<void>;
    /** Assert the target has attribute `name` (optionally equal to `value`). */
    toHaveAttribute(name: string, value?: string): Promise<void>;
    /** Capture/compare a screenshot stored under `name`. */
    toHaveScreenshot(name: string): Promise<void>;
  }

  /** Arguments passed to each test body. */
  export interface TestArgs {
    page: Page;
  }

  /** Register a test. Bodies run against a per-spec mounted app. */
  export function test(name: string, fn: (args: TestArgs) => void | Promise<void>): void;

  /** Begin an assertion against a `Locator` or the `Page`. */
  export function expect(target: Locator | Page): Matchers;

  /** The page global; also delivered via each test's `{ page }` argument. */
  export const page: Page;
}
```

```rust
/// Given `cargo metadata` JSON, locate `package` and return the path to
/// `filename` bundled alongside its `Cargo.toml`.
pub fn find_module_dts(metadata_json: &str, package: &str, filename: &str) -> Option<PathBuf> {
    let meta: Metadata = serde_json::from_str(metadata_json).ok()?;
    let pkg = meta.packages.into_iter().find(|p| p.name == package)?;
    let dir = Path::new(&pkg.manifest_path).parent()?;
    Some(dir.join(filename))
}

/// Locate the `supersolid` package's bundled `supersolid.d.ts`.
pub fn find_supersolid_dts(metadata_json: &str) -> Option<PathBuf> {
    find_module_dts(metadata_json, "supersolid", "supersolid.d.ts")
}
```

```rust
/// One editor-types module projected by `cargo superui install`.
pub struct ProjectedModule {
    /// cargo-metadata package that ships the canonical `.d.ts`.
    pub package: &'static str,
    /// Canonical `.d.ts` filename beside that package's `Cargo.toml`.
    pub dts_filename: &'static str,
    /// tsconfig `paths` key / import specifier.
    pub specifier: &'static str,
    /// Location under `superui_modules/` (also the tsconfig marker tail).
    pub subpath: &'static str,
    /// Absence of a required module's package is a hard error; optional is a skip.
    pub required: bool,
}

impl ProjectedModule {
    /// Unique substring identifying this module's `paths` entry in a tsconfig.
    pub fn marker(&self) -> String {
        format!("superui_modules/{}", self.subpath)
    }
    /// The `paths` value pointing at the projected `index.d.ts`.
    pub fn index_path(&self) -> String {
        format!("./superui_modules/{}/index.d.ts", self.subpath)
    }
}

/// The modules `cargo superui install` projects, in order. supersolid is the
/// primary (required) module; superui/test types are optional.
pub fn projected_modules() -> Vec<ProjectedModule> {
    vec![
        ProjectedModule {
            package: "supersolid",
            dts_filename: "supersolid.d.ts",
            specifier: "supersolid",
            subpath: "supersolid",
            required: true,
        },
        ProjectedModule {
            package: "superui",
            dts_filename: "superui-test.d.ts",
            specifier: "superui/test",
            subpath: "superui/test",
            required: false,
        },
    ]
}
```

```rust
    let app_dir = match flag(args, "--path") {
        Some(p) => PathBuf::from(p),
        None => current_package_dir()?,
    };

    let metadata = run_cargo(&["metadata", "--format-version", "1"])?;

    // 1. Project each module's types (derived artifacts — always overwrite).
    for m in projected_modules() {
        let dts_src = match find_module_dts(&metadata, m.package, m.dts_filename) {
            Some(p) => p,
            None if m.required => {
                return Err(format!(
                    "no `{}` dependency resolved — add it (or `superui`) to Cargo.toml",
                    m.package
                )
                .into());
            }
            None => {
                println!("skip {} types — `{}` not in dependency graph", m.specifier, m.package);
                continue;
            }
        };
        let dts = std::fs::read_to_string(&dts_src)
            .map_err(|e| format!("reading {}: {e}", dts_src.display()))?;
        let module_dir = app_dir.join("superui_modules").join(m.subpath);
        std::fs::create_dir_all(&module_dir)?;
        let index = module_dir.join("index.d.ts");
        std::fs::write(&index, &dts)?;
        println!("wrote {}", index.display());
    }

    // 2. tsconfig: create from template if absent, else guide per module.
    let tsconfig = app_dir.join("tsconfig.json");
    if !tsconfig.exists() {
        std::fs::write(&tsconfig, TSCONFIG_TEMPLATE)?;
        println!("wrote {}", tsconfig.display());
    } else {
        let existing = std::fs::read_to_string(&tsconfig)?;
        for m in projected_modules() {
            if tsconfig_has_path(&existing, &m.marker()) {
                println!("ok   {} (already maps {})", tsconfig.display(), m.specifier);
            } else {
                println!(
                    "note {} exists but does not map {} — add to compilerOptions.paths:\n      \"{}\": [\"{}\"]",
                    tsconfig.display(),
                    m.specifier,
                    m.specifier,
                    m.index_path()
                );
            }
        }
    }

    // 3. .gitignore the derived tree.
    let gitignore = app_dir.join(".gitignore");
    let existing = std::fs::read_to_string(&gitignore).unwrap_or_default();
    if gitignore_needs_entry(&existing) {
        let mut next = existing;
        if !next.is_empty() && !next.ends_with('\n') {
            next.push('\n');
        }
        next.push_str(GITIGNORE_ENTRY);
        next.push('\n');
        std::fs::write(&gitignore, next)?;
        println!("updated {}", gitignore.display());
    }

    println!("done: superui IDE types installed in {}", app_dir.display());
    Ok(())
```
