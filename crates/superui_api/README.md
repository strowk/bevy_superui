# superui_api

Retired stub, kept only so dependents' manifests keep resolving.

The DOM/Web API surface now lives in [`superui_js`]: the JS shadow DOM defines
`document`, nodes, events, and layout reads, and each engine backend registers
the host imports.

## Part of bevy_superui

This is an internal crate of [bevy_superui].

- Docs and live demos: <https://strowk.github.io/bevy_superui/>
- Source: <https://github.com/strowk/bevy_superui>
