# superui_test_engine

A Playwright-shaped end-to-end test framework for [bevy_superui] apps
(native-only).

TypeScript specs run against a real superui app with auto-waiting DOM assertions
and screenshot diffing, driven by the `superui_test` CLI (with an egui UI mode).

## Part of bevy_superui

This is a tool for [bevy_superui].

- Docs and live demos: <https://strowk.github.io/bevy_superui/>
- Source: <https://github.com/strowk/bevy_superui>
